📱 QR Code สำหรับนักเรียน

นำ QR Code นี้ไปติดหน้าห้องสมุด เมื่อนักเรียนสแกน จะเปิดระบบนี้และสามารถเลือกเช็กชื่อ ยืม หรือคืนหนังสือได้

ลิงก์ของหน้านี้

วิธีใช้งาน

  1. เปิดหน้าเว็บนี้
  2. สแกน QR Code ด้วยโทรศัพท์
  3. เลือกเมนู เช็กชื่อ / ยืม / คืน
  4. กรอกข้อมูลแล้วกดบันทึก

หมายเหตุ: QR Code จะชี้มายังที่อยู่ของหน้าเว็บนี้ หากเปิดเป็นไฟล์ในเครื่อง QR จะใช้งานได้เฉพาะอุปกรณ์ที่เข้าถึงไฟล์นั้นได้ ควรนำไฟล์ขึ้นโฮสต์ก่อนเพื่อให้โทรศัพท์ทุกเครื่องสแกนเข้าถึงได้
